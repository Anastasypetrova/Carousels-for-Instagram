# Входящие материалы

Сюда кладутся фотографии, видео и текст для поста.

- Фото: `.jpg`, `.png`, `.webp`, `.avif`, `.heic`
- Видео: `.mp4`, `.mov`
- Текст: `text.md` — просто текстом, агент разложит его по слайдам

Имена файлов любые, переименовывать ничего не нужно: в спеке на фото ссылаются
по имени файла, регистр и пробелы значения не имеют.

Содержимое этой папки не попадает в git — материал остаётся приватным до тех
пор, пока пост не опубликован.
