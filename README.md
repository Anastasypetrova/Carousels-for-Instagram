# Агент для инстаграма

Собирает посты для инстаграма Анастасии: берёт её фотографии, видео и текст,
раскладывает текст по кадрам и готовит всё к публикации.

Правила, по которым он работает, лежат в двух файлах и читаются перед каждой
задачей:

- **`GUIDELINES.md`** — формат, слайды, обработка фото, где может лежать текст;
- **`VOICE.md`** — как звучит её текст, под что агент его правит.

Поправить строчку в этих файлах — значит изменить поведение агента. Код трогать
не нужно.

## Цепочка

1. Анастасия кладёт в `input/` фотографии, видео и текст;
2. агент переписывает текст в её голосе и показывает, что получилось;
3. агент собирает пост;
4. агент отдаёт готовые файлы в максимальном качестве;
5. Анастасия выкладывает их сама.

Публикацию агент не делает намеренно. Выкладывая из приложения, вы получаете
трендовые звуки, до 20 слайдов и выбор момента — ничего из этого публикация
через API не даёт.

## Что уже работает

| | |
|---|---|
| Карусель из фотографий | да |
| Поиск места для текста | да, с проверкой глазами |
| Обработка фото | да: кроп, яркость, резкость, виньетка |
| Видео в 9:16 и 4:5 | да |
| Публикация | нет и не планируется — выкладывает Анастасия |

## Качество

Картинки отдаются **1440×1800 PNG** — это максимальная ширина, которую
Instagram оставляет при загрузке.

Чтобы этот размер что-то значил, весь тракт идёт без промежуточных потерь:

- фото готовится сразу в разрешении рендера (2880 px), а не в размере холста —
  иначе браузер растягивал бы его вдвое и съедал детализацию;
- промежуточный файл — PNG, не JPEG, чтобы артефакты не запеклись в финал;
- слайд снимается в двойном размере и уменьшается по Ланцошу — от этого чистые
  края у букв и виньетки;
- резкость наводится с радиусом под масштаб рендера, иначе при уменьшении она
  бы наполовину терялась.

## Запуск руками

```bash
npm install
npm run render -- posts/имя.json      # карусель
npm run video -- input/clip.mov --kind reel
```

Результат — в `out/<слаг>/`: пронумерованные PNG 1440×1800, `caption.txt` и
`preview.html`, где весь пост виден одной лентой.

Первый запуск на новой машине требует браузер для рендера:

```bash
npx playwright install chromium
```

ffmpeg доустанавливать не нужно, он идёт внутри пакета.

### Флаги рендера

| Флаг | Что делает |
|---|---|
| `--candidates` | отрендерить все варианты размещения текста, чтобы выбрать |
| `--guides` | нарисовать выбранную рамку и обрезку до квадрата |
| `--size 4:5` | холст: `4:5`, `1:1`, `9:16` |
| `--out <папка>` | куда складывать |
| `--jpg` | JPEG вместо PNG, если размер файлов мешает |

## Спека поста

```json
{
  "slug": "mir-vsegda-za",
  "size": "4:5",
  "handle": "@anastasypetrova",
  "slides": [
    { "photo": "IMG_4821", "text": "Мир не против тебя" },
    { "photo": "IMG_4822", "text": "Перестань думать, что мир против тебя." },
    { "photo": "IMG_4823", "text": "…", "box": { "x": 0.08, "y": 0.09, "w": 0.4 } }
  ],
  "caption": "Текст поста."
}
```

| Поле слайда | Что |
|---|---|
| `photo` | имя файла из `input/` — регистр и пробелы не важны |
| `text` | текст слайда |
| `size` | кегль: `s`, `m` (по умолчанию), `l` |
| `box` | закрепить место вручную: доли кадра `{x, y, w}` |
| `tone` | `light` — белый текст, `dark` — тёмный, `auto` — по фону |
| `vignette` | сила пятна под текстом; `0` выключает |
| `focus` | кроп: `centre`, `north`, `south`, `auto` |
| `grade` | обработка: `base` (по умолчанию), `soft`, `deep`, `none` |

## Как выбирается место для текста

`src/analyze.mjs` строит по кадру карту детализации и оценивает каждое возможное
место по пяти признакам: сколько под ним деталей, насколько ровный фон, хватает
ли контраста цвету букв, уравновешивает ли оно фигуру в кадре и попадает ли на
линию третей.

Дальше — обязательный шаг, который нельзя автоматизировать: **агент смотрит на
отрендеренный слайд глазами.** Геометрия не отличает гладкое небо от гладкого
платья, поэтому автоматика иногда предлагает положить текст на человека. Флаг
`--candidates` рендерит все варианты сразу, чтобы выбрать быстро.

## Шрифт

Inter Regular, файлы лежат в `fonts/`. В референсных каруселях — системный шрифт
iOS; Inter это тот же неогротеск, поэтому слайды выглядят одинаково на любой
машине и при рендере ничего не скачивается.
